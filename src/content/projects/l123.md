l123 revives the fast, tactile feel of classic spreadsheets without getting trapped in nostalgia. The goal is simple: preserve the speed and discipline of the old interaction model while speaking modern Excel fluently.

**Latest release: 1.4.0 (September 2026).** Upgrades the engine to IronCalc 0.8.3. Excel-authored theme colors now resolve against the workbook theme, so default-palette fills and fonts import correctly; column widths and fonts survive round-trips cleanly. Install or upgrade via Homebrew (`brew install duane1024/l123/l123`).
